# Hi, I'm Mario 👋

I like building small, self-hosted tools that my family and friends actually use: finance tracking, homeschool
apps, playoff brackets and more. Most of it is TypeScript and React, with some Go when it fits.

## Tech I work with

- **Languages:** TypeScript · JavaScript · Go · Python
- **Frontend:** React · Next.js · Svelte · Tailwind CSS · Vite
- **Backend & data:** Node.js · Express · PostgreSQL · SQLite · Drizzle ORM
- **Infra:** Docker · Tailscale · Vercel
